设置管理员密码

第一次登录后必须设置密码。设置完成后，网页用密码登录；口令只留给命令行和脚本。

强度：较强
  • {{c.text}}
    •

设置之后会发生什么

  • 网页登录只接受密码。口令不再能登录网页。
  • 口令继续给命令行和脚本用，可以单独吊销。
  • 密码用慢哈希保存，不保存明文，日志里也不出现。
  • 其他已登录的会话会立即失效。
  • 连续输错 5 次，这个账户的网页登录会锁定 15 分钟。
忘记密码
网页上没有“忘记密码”。在运行 Agent 的电脑上执行：
deskhubctl admin-password-reset
