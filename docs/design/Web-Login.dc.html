管理员登录

{{m.label}}

还没设置过密码？切到“口令（首次）”登录，进去后设置。忘记密码，要在运行 Agent 的电脑上用命令行重置。

口令在管理员凭据文件的 token 字段里。复制过来，粘贴到下面。登录后会要求你马上设置密码。

设置密码之后，网页就不再接受口令。口令继续给命令行和脚本用。

口令和密码都不要放进网址、命令行参数或截图。浏览器只保留 30 分钟的会话，不保存它们。
