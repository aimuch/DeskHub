充电保护

实验

电量到上限就停止充电，降到回充点再充。默认关闭，开启要二次确认。

保护措施
  • 电池电压不小于 4.30 V，或芯片温度不小于 65 °C：立刻停充
  • 连续 3 个有效样本才切换，两次切换至少隔 60 秒
  • 读不到电量：恢复正常充电，由芯片自己的终止机制兜底
  • 每次开关都读回确认，并记入日志
