# 设计稿源文件

这里是新设计的设计稿源文件，共 24 张画板（`*.dc.html`），加一份画布索引 `canvas.json`。
范围见 [product-scope.md](../product-scope.md)，规则见 [rules.md](../rules.md)。

画板文件开头的 `./support.js` 由设计画布提供，不在仓库里。要看设计稿，需要用支持这种格式的设计画布打开。
画板里的读数、设备编号和旧固件的校验值都是**示意数据**，不是真实读数。

### 其他约定

- 状态环四段的角度（从 3 点钟方向顺时针）：网络 278° 到 352°，电脑 8° 到 82°，电源 98° 到 172°，时间 188° 到 262°。线宽 20 px，圆弧端是圆头。
- 仪表是 270° 的圆弧，缺口在下方，从 135° 开始顺时针。读数无效时留空，不填 0。
- 设备字体是 28 px 与 20 px 的思源黑体子集；字库没有 `°`、`琥`、`珀`，所以温度写“度”，第三个主题叫“暖橙”。
- 主要触摸热区不小于 56×56 px。
- 没有动作时，总览不画任何卡片，“动作”页只写一行字“尚无可用动作”。不画“设置网络与配对”卡片（2026-10-29 你说它没必要、占屏幕）。缺什么，状态环和顶栏图标已经说明。
- 状态环的四段只是显示，不能点：右上青色 = Wi-Fi 已连接，右下绿色 = 电脑（Agent）已连接，左下橙色 = 电源读数新鲜且没有故障，左上紫色 = 时间有效。亮 = 正常，暗 = 没有数据或有问题。能点的是中间的时钟（进时钟页），和顶栏左右两块（左进“连接”，右进“电源”）。

## 改设计稿时

先改画布，再把改过的文件同步到这里，并用中文提交。

### 设备顶栏（图标，没有文字）

画板 `Dev-Header` 是权威。要点：

| 项 | 值 |
| --- | --- |
| 位置 | 第一行图标顶边 14 px。左边从 x=38 开始：Wi-Fi，电脑。右边距右边 36 px：USB，闪电，电池。点击范围不变：左右各 212×62 px |
| 圆角 | 屏幕四角是圆角，半径按 80 px 估算（Waveshare 没公布）。靠近角的位置按曲线往里收，见 `kCornerR` |
| 大小 | Wi-Fi 26×24，电脑 26×24，USB 22×24，闪电 14×22，电池 51×24（本体 46×22，边 2 px，圆角 7，右边的小头 3×9） |
| Wi-Fi | 已连接：青色。正在连接：青色，每秒闪一次，不带斜杠。没配置、没连上：灰色加斜杠 |
| 电脑 | 在线：绿色。离线、未配对：灰色加斜杠 |
| USB | 有 USB 供电才显示，否则留空 |
| 电池 | 轮廓和填充的颜色随电量：大于 20% 绿，11% 到 20% 橙，10% 及以下红。填充是这个颜色的 40%，数字压在上面，用正文色、15 px，**不带 %**。未知：问号，不填充。没有电池：灰色加斜杠。异常：橙色，感叹号 |
| 闪电 | 只在“充电中”显示，画在电池左边。已充满不显示 |
| 数字开关 | “设置 → 外观 → 电池百分比”：显示或隐藏。隐藏后只有填充 |
| 不显示旧数据 | 读数过期、异常或未知：不画 USB、不画闪电、不填充 |
