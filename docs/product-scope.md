# 产品范围

状态：2026-10-28 定稿（决策 D1–D9，见第 10 节）。规则见 [rules.md](rules.md)。
旧规格 `DESKHUB_SPEC.md` 在 `archive/v0.2` 分支里，只供参考，不再有效。

## 1. 定位

DeskHub 是放在电脑桌上的触屏控制器。它只做三件事：

1. 用触屏、快捷键或命令行切换显示器输入源。
2. 看电脑的关键状态。
3. 当桌面时钟，并管理设备自己的显示、电源和连接。

它不是 SmartHub 的屏幕或节点（D1）。

## 2. 目标环境

- 家里或办公室的局域网。USB 供电为主，电池只做短时备用。
- 电脑端只做 macOS，显示器控制用 BetterDisplay。Windows 和 Linux 没验证过，不承诺（D2，规则 R4）。
- 设备是 Waveshare ESP32-S3-Touch-AMOLED-2.16：480×480 AMOLED、触摸、Wi-Fi、AXP2101 电源芯片、RTC、16 MiB Flash、8 MiB PSRAM。

## 3. 功能的三种状态

每个功能都有一个状态（规则 R1）。

| 状态 | 含义 |
| --- | --- |
| 已验证 | 有测试或实测证据。默认可用。 |
| 实验 | 默认关。开启要二次确认。失败时回到安全默认值。设备屏幕上不显示“实验”字样（你在 2026-10-29 决定）。 |
| 不可用 | 硬件不支持、没装电池或没配置。界面写出原因，不隐藏入口。 |

功能从“实验”升级为“已验证”，必须有证据（测试或实测记录）。

## 5. 设备页面

设计范围是 6 个主要页面，外加设置里的详情页和状态页。

| 页面 | 内容 |
| --- | --- |
| 总览 | 时钟、状态环、两个常用动作卡片、导航 |
| 动作 | 全部已授权的动作，按卡片排列 |
| 电脑 | CPU 与内存仪表、网络收发 |
| 设置 | 列表入口 |
| 电池与电源 | 电量仪表、电池电压、USB 电压、充电状态、芯片温度、充电保护状态 |
| 连接与配对 | Wi-Fi、Agent、IP、信号强度、配对状态 |

设置的详情页：显示与亮度、外观、桌面时钟、设备信息与重启。
状态页：首次配对、离线、数据过期、错误、关屏与唤醒。

## 6. 管理台页面

概览、设备、动作与显示器、命令记录、布局与显示、电源、固件、访问、外观，共 9 页。
另有三个流程：首次用口令登录并设置密码、以后用密码登录、信任证书（规则 R6、R8）。

“布局与显示”里的预览，直接渲染真实的设备界面，不画示意图。

## 7. 首次配网（D8）

- 保留 USB 配对。
- 另加“长按设备按键进入配网页”。这要求人在设备旁边（规则 R7）。

## 8. 设计语言（D9）

设备界面和管理台用同一套设计变量：

- 渐变背景；四种语义色：Wi-Fi 青、电脑绿、电源橙、时间紫。
- 发光的圆环、玻璃质感的卡片。
- 主要触摸热区不小于 56×56 px。
- 设备字体是 28 px 与 20 px 的思源黑体子集。字库没有 `°`、`琥`、`珀`，所以第三个主题叫“暖橙”，温度写“度”。
- 管理台跟随系统的浅色或深色。

### 8.1 可定制（D11、D12）

所有颜色、字号、圆角、间距和动效，都是设计变量。主题、语言、字体、布局都是“数据包”：可以换，可以导入导出，不含代码。

管理台可以改语言、字体、文字大小、主题、配色和密度。

设备的限制来自字库和内存：

- 主题与配色：可以，它们只是颜色变量。
- 语言：先做中文和英文。英文只需要 ASCII；其他语言要先补字库。
- 文字大小：先做三档（小、标准、大），三档字号都要预先编进固件。
- 字体：暂不支持更换（D13：先不加数据分区）。

规则见 [rules.md](rules.md) 的 R9。

## 9. 明确不做

- 任意命令、脚本或由参数组成的任意地址。
- 把设备或 Agent 暴露到公网。
- 动态应用商店和运行时插件。
- 没有验证的 Windows 和 Linux 显示器后端。

## 11. 待实测的事项

这些事实决定部分功能的细节。在测到之前，文档里一律写“未知”。

1. AXP2101 上电后，ADC、电池检测、电量计是否已经被启用。它决定 C5 能不能直接读到数据。
2. 板上有没有电池温度探头。硬件记录说原理图有热敏电阻 RP4，位置没确认；SmartHub 认为没有。它决定 TS 引脚怎么处理。
3. 电量计估算与实际电池的偏差。做法是一次完整充放电，用外部表对照。
4. 暂停充电后，USB 是否仍稳定供电；重启和 USB 重插后，充电使能位是否保留。
5. 电池的允许充电电流、温度范围、厂家和保护板。现在只有标签：103030、1000 mAh、3.7 V、4.2 V。
6. 扬声器是否安装：2026-10-29 你说板上有。声音芯片是否应答，看 USB 状态 `capabilities.audio`；2026-10-31 你听到了 0.3.7 的试听音，扬声器是接着的。你要音量可调，0.3.8 加了三档。
7. BetterDisplay 切走显示器后，控制通道是否还在，读回是否可用。
8. 设备加载自定义字体或语言包时，内存占用和刷新速度。D13 先不加数据分区，所以暂不测。
