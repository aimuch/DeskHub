# 屏幕上更换 Wi-Fi（软键盘）设计

状态：**设计中**（2026-11-03），没有实现，没有测试。你说“开始设计软键盘”之后写的。
范围项是 [product-scope.md](product-scope.md) 的 N3。设计稿是 `docs/design/` 的三张画板：`Dev-WifiList`、`Dev-Keyboard`、`Dev-WifiResult`。
标“我定的”的地方，是规则没有规定、由我选的值，请你审。标“要你决定”的地方，在你决定之前不实现。

## 1. 做什么，不做什么

做：在设备屏幕上选一个附近的 Wi-Fi，用软键盘输入密码，设备试连。连上了才保存；连不上就回到原来的 Wi-Fi。

不做：
- **不做首次配对。** 设备连 Agent 还要 CA 证书和设备令牌。CA 有几千个字符，不能在屏幕上打。首次配对仍然用 USB 或热点（D8、R7）。
- 不改 Agent 地址、CA、令牌、授权。这一页只改 Wi-Fi 名称和密码。
- 不支持企业 Wi-Fi（要用户名和证书）和 WEP。列表里显示它们，但变暗，写“不支持”。
- 不能输入中文。Wi-Fi 名称和密码只能输入 ASCII（键盘上能打出全部 95 个可打印字符，含空格）。名称里有中文的 Wi-Fi，只能从扫描列表里选。

## 2. 流程

1. 设置 → 连接与配对 → “更换 Wi-Fi”（画板 `Dev-WifiList` ①）。
2. 设备扫描附近的 Wi-Fi，按信号强弱排序，正在用的那个标“当前”。最后一行是“其他（手动输入名称）”（②）。
3. 点一个加密的 Wi-Fi，进软键盘（画板 `Dev-Keyboard`）。点开放的 Wi-Fi，直接去第 5 步。
4. 输入密码，点“完成”。
5. 设备用新的名称和密码试连，屏幕写“正在连接”和剩下的秒数（画板 `Dev-WifiResult` ①）。**这时还没有保存**，存储里仍是原来的 Wi-Fi。
6. 结果：
   - 连上，拿到 IP，设备已配对时也连上了电脑：保存，写“已连接”（②）。
   - 连上，但连不上电脑：问“仍然使用”还是“改回原来的”（③）。60 秒没人点，**改回原来的**（我定的：宁可不变，也不让设备失联）。
   - 没连上（密码错、找不到、超时）：不保存，改回原来的 Wi-Fi，写原因（④）。可以“重新输入”。
7. 没有配对的设备：只看能不能拿到 IP，不检查电脑。

## 3. 键盘

画板 `Dev-Keyboard`。屏幕是 480×480 的圆角屏，主要触摸热区不能小于 56×56（D9）。所以：

- **每行 7 个键**，键 58×56，间隔 4 px，一行宽 430 px。一般手机键盘每行 10 个键，键会窄到 40 px，比规则小，所以不用 QWERTY。字母按 a 到 z 的顺序排（我定的）。
- 键盘页**不画顶栏和底部页签**，否则放不下 5 行键。左上角“返回”回到 Wi-Fi 列表。
- 字母页：`abcdefg` / `hijklmn` / `opqrstu` / 大写键 `vwxyz` 删除键。大写键点一下切换大写，再点一下切回小写，切换后一直保持（我定的；密码里大写字母常连在一起）。大写开着时键是选中色。
- 最下面一行：`123`（切到数字和符号）、`空格`、`完成`。
- 数字和符号有两页：
  - 第一页：`1234567` / `890-_.@` / `!#$%&*+` / `1/2` `?=/:;` 删除键。
  - 第二页：`()[]{}<` / `>"',` `` ` `` `~\` / `|^` / `2/2` 删除键。
  - 两页合起来是全部 32 个 ASCII 符号。最下面一行的 `123` 在这两页里变成 `abc`。
- 删除键和大写键用 LVGL 自带的图标（`LV_SYMBOL_BACKSPACE`、`LV_SYMBOL_UP`），不用字库里没有的字。
- 键按下时变成选中色，松手才输入。手指滑出键再松手，不输入（我定的）。
- 长按删除键连续删除：按住 500 毫秒后，每 80 毫秒删一个（我定的）。

### 输入框

- 输入框在键盘上面，右边写长度，例如 `10/63`。
- 密码画成 `*`（字库里没有 `•`）。**是否允许显示明文，要你决定**，见第 6 节。
- “完成”在长度不对时变暗，下面一行写原因：密码要 8 到 63 个字符，或者正好 64 个十六进制字符（WPA2 的规定）。名称是 1 到 32 个字节。
- 不能再输入时（63 个字符，且不是十六进制），按键不响应，下面一行写“最多 63 个字符”。

### 手动输入名称

“其他”先用同一个键盘输入名称（不遮住，名称不是秘密），再问“有密码”还是“没有密码”。名称看不见的 Wi-Fi（隐藏网络）只能这样加。

## 4. 失败模式

先写会怎么出错，再写代码（你的测试规则）。每一条都要有测试或在真机上看。

| 编号 | 会怎么出错 | 设计怎么挡住 |
| --- | --- | --- |
| W1 | 密码输错，保存后设备再也连不上，只能 USB 重配 | 先试连，连上才保存。试连失败自动改回原来的 Wi-Fi |
| W2 | 连上新 Wi-Fi，但电脑不在这个局域网里，设备和电脑失联 | 已配对时，连上后再连一次电脑。连不上要人选；60 秒没人选就改回 |
| W3 | 试连到一半断电或重启 | 试连时存储里仍是旧的，开机用旧的。保存只用一次已有的 `save_config`，要么全写进去，要么不写 |
| W4 | 改回原来的 Wi-Fi 也失败（例如原来的路由器关了） | 写“原来的 Wi-Fi 也没连上”，存储不变，设备照常按旧配置重试，和现在断网时一样 |
| W5 | 配对热点开着时扫描或试连，打乱热点 | 热点开着时“更换 Wi-Fi”变暗，写“配对热点打开时不能用”。试连期间不允许开热点（长按按键无效，写原因） |
| W6 | 扫描时 Wi-Fi 任务又在重连，两边抢 Wi-Fi 驱动 | 用已有的 `network_hold` 让 Wi-Fi 任务暂停重连，结束后放开（改基线 core，K7 单独提交） |
| W7 | 密码进日志、USB 状态或上报 | 不打日志；USB 状态只给阶段和原因，不给名称和密码；用完清零。Wi-Fi 驱动自己会打印名称（不是密码），和现在一样 |
| W8 | 人走开，密码留在内存和屏幕上 | 键盘页 3 分钟没有触摸就退出并清零（我定的）。离开键盘页就清零 |
| W9 | 打字时屏幕熄灭 | 键盘页显示时保持亮屏（和配网页一样）。夜间限亮、故障限亮仍然有效（K5）。熄屏后的第一次触摸只唤醒，不输入 |
| W10 | 长度、字符不合规的密码被交给驱动，结果说不清 | 只接受 8 到 63 个 ASCII 可打印字符或 64 个十六进制字符；名称 1 到 32 字节。沿用 `provision.py` 的同一套校验 |
| W11 | 扫描结果里有同名的多个热点、空名称、名称含不可显示的字 | 同名只留信号最强的一行；空名称不显示；字库没有的字显示成缺字框，但仍然能选 |
| W12 | 扫描没有结果或失败 | 写“没有找到 Wi-Fi”和“重扫”。扫描 10 秒没有结果算失败（我定的） |
| W13 | 企业 Wi-Fi、WEP 被选中 | 变暗，写“不支持”，点了不进键盘 |
| W14 | 试连时点“返回”或别的页签 | 试连页没有页签；“取消”等同于失败：改回原来的 |
| W15 | 新旧是同一个 Wi-Fi、同一个密码 | 照样试连，结果相同就保存，不特殊处理 |
| W16 | 宣称“已连接”但其实没有 IP | 只有拿到 IP 才写“已连接”（K3） |

## 5. 不看屏幕也能核对

USB 状态加一个只读的 `wifi_change` 对象：阶段（idle、scanning、typing、testing、checking_agent、asking、saved、reverted）、原因（WRONG_PASSWORD、NOT_FOUND、TIMEOUT、AGENT_UNREACHABLE、USER_REVERTED、HOTSPOT_OPEN）和最近一次结果的时间。不带名称和密码。`tools/provision.py --status` 打印它。

## 6. 要你决定

1. **显示明文（K4）。** K4 写着“Wi-Fi 密码只用隐藏输入”。在小键盘上看不见自己打了什么，很容易打错，而且要整个重打。我的建议：加一个“按住显示”键，按住时显示明文，松手马上遮住，离开键盘页也遮住。这算放宽 K4 的字面意思，要你明确决定。你不同意，就只画 `*`，设计稿里那个键去掉。
2. **字母顺序。** 我选了 a 到 z 的顺序，因为每行只能放 7 个键，QWERTY 排不下。如果你更想要 QWERTY，键会窄到 40 px 左右，违反 56 px 的规则（D9），也要你决定。
3. **连不上电脑时的默认。** 我选 60 秒后改回原来的。另一种是默认“仍然使用”。
