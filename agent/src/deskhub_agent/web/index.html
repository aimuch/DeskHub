管理员登录

还没设置过密码？切到“口令（首次）”登录，进去后设置。忘记密码，要在运行 Agent 的电脑上用命令行重置。

口令在管理员凭据文件的 token 字段里。复制过来，粘贴到下面。登录后会要求你马上设置密码。

设置密码之后，网页就不再接受口令。口令继续给命令行和脚本用。

口令和密码都不要放进网址、命令行参数或截图。浏览器只保留 30 分钟的会话，不保存它们。

信任证书

浏览器提示不受信任时

管理台的证书由你自己的 CA 签发，浏览器默认不认识它。信任一次，以后就不再提示。

  1. 找到 CA 证书

    在运行 Agent 的电脑上，它是生成证书时得到的 ca.pem（例如 ~/.config/deskhub/tls/ca.pem）。它是公开的证书，不含私钥。

  2. 把它加入系统并设为信任

    macOS：双击 ca.pem，加入“登录”钥匙串，再在“钥匙串访问”里打开它，把“信任”设为“始终信任”。系统会请你输入自己的密码；这一步由你亲自做。

  3. 重启浏览器，再打开管理台

    地址栏出现锁形图标，就表示信任生效。

管理台不提供证书下载：从一个还不被信任的页面下载“信任根”，等于没有验证。请直接从 Agent 所在的电脑上取文件。

只在本机使用、不接设备时，也可以改用本机回环地址 http://127.0.0.1:8765/manage/。它没有证书，设备连不上。

设置管理员密码

第一次登录后必须设置密码。设置完成后，网页用密码登录；口令只留给命令行和脚本。

    设置之后会发生什么

    • 网页登录只接受密码。口令不再能登录网页。
    • 口令继续给命令行和脚本用，可以单独吊销。
    • 密码用慢哈希保存，不保存明文，日志里也不出现。
    • 其他已登录的会话会立即失效。
    • 连续输错 5 次，这个账户的网页登录会锁定 15 分钟。
    忘记密码

    网页上没有“忘记密码”。在运行 Agent 的电脑上执行：

    deskhubctl admin-password-reset
